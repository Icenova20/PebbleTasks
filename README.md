# PebbleTasks
Pebble Tasks is a Pebble Application which enables Task Lists and Tasks. 

SDK 4.9
https://developer.repebble.com/docs/c/Foundation/

A task list is a conceptual organization of tasks

A task is a TODO item

PebbleTasks uses a SimpleMenu to navigate the available tasklist items. 

Upon selection of a TaskList, PebbleTasks displays the tasks that are still open

Dictation API is used to either add a tasklist by name, or a task item in a task list.
